# Japo Dev · Landing

Landing page de **Japo Dev**, desarrollo de software a medida para empresas en Paraguay.

- Sistemas: ERP a medida, veterinarias, e-commerce, punto de venta, CRM y RRHH.
- Incluye un ejemplo animado de e-commerce (tienda ficticia "Rumbo") con recorrido de compra y carrito.
- Contacto: WhatsApp +595 982 331 005 · Instagram [@japodev.py](https://instagram.com/japodev.py)

## Estructura

```
index.html   Página completa (HTML + CSS + JS, sin dependencias)
img/         Logo y fotos
```

Es un sitio estático: se puede publicar tal cual con GitHub Pages, Netlify o Vercel.
Para verlo en local, abrí `index.html` en el navegador.
